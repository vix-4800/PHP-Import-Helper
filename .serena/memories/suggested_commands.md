# Suggested Commands

- `npm run check-types`: TypeScript type check.
- `npm run lint`: ESLint over `src`.
- `npm run package`: typecheck, lint, production bundle.
- `npm run test:unit`: compile tests, run unit suite.
- `npm run test:integration`: compile, bundle, run VS Code integration tests.
- `npm test`: unit + integration.
- `npm run compile-tests`: emit tests to `out`.
- `npm run watch`: parallel watch build. 

Use `rg` / `rg --files` for search.
